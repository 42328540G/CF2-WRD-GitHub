# CF2-WRD v1.1 Release Notes

This release aligns the public implementation with the Round 7 manuscript definition.

## Main changes

- Fixed architecture parameter count at **8,989,568 (8.99 M)**.
- Pearson selection now controls a training-derived local **activity mask** rather than structurally shrinking the model.
- The local ACFFM alignment remains fully parameterized as 1024→512; forward computation uses active local inputs and matching weight columns.
- Parameter count is invariant to the number of active local dimensions.
- INT8 documentation now states that quantization changes precision, not parameter count.
- Removed unverified model-file-size claims from deployment documentation.
- Updated Fig. 1 wording from feature removal to feature masking.
- Added parameter-count invariance testing and updated release verification.

The private dataset/checkpoint are not included, so manuscript accuracy/F1/FPS values remain reported experimental results rather than outputs regenerated by this public release.
